# הצוות

צוות פיתוח שעובד בשבילך במחשב: מתכנת, מעצב, בודק, כותב תוכן ועוד. כותבים לו במילים פשוטות מה צריך, והוא בונה, בודק ומעלה אתרים ותוכנות.

התוכנה עובדת מעל **Claude Code** ו/או **Codex**, שמותקנים אצלך ומחוברים למנוי שלך. הממשק בעברית, והכול רץ על המחשב שלך.

## הורדה והתקנה

1. נכנסים ל-[**Releases**](../../releases/latest) ומורידים את `Tzevet-Setup-<גרסה>.exe`.
2. לוחצים פעמיים על הקובץ. לא צריך הרשאות מנהל.
3. Windows עלול להציג "Windows הגן על המחשב שלך", כי הקובץ עוד לא חתום בתעודה בתשלום. לוחצים **"מידע נוסף"** ← **"הפעל בכל זאת"**.
4. בסוף ההתקנה התוכנה נפתחת בדפדפן, ואשף קצר עוזר להתקין ולחבר את מה שחסר (Git, ‏Claude Code או Codex).

**דרישות:** Windows 10 או 11 (‏64 ביט), ומנוי ל-Claude או ל-ChatGPT (בשביל Codex).

## עדכונים

התוכנה בודקת לבד פעם ביום אם יש גרסה חדשה כאן. בהגדרות ← עדכונים בוחרים אם לעדכן אוטומטית או רק לקבל הודעה. כל גרסה חתומה דיגיטלית, והתוכנה מתקינה רק עדכון שהחתימה שלו תקינה.

## הסרה

הגדרות Windows ← אפליקציות ← אפליקציות מותקנות ← **הצוות** ← הסר. בהסרה שואלים אם למחוק גם את הנתונים (ברירת המחדל: לא). קבצי הפרויקטים שלך לא נמחקים בשום מקרה.

## תקלה?

בתוכנה: הגדרות ← בדיקת מערכת ← "צור דוח תקלה" ← "דווח ב-GitHub". או ישירות כאן ב-[Issues](../../issues). דף התקלות גלוי לכולם, ולכן לא מצרפים לדיווח סיסמאות או פרטים אישיים.
